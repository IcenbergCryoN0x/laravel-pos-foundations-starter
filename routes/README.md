# Routes

No Laravel routes are implemented in this scaffold. The assignment calls for these paths in `web.php`:

| Path | Planned page | Planned controller |
| --- | --- | --- |
| `/` | Landing page | `PageController` |
| `/about` | About page | `PageController` |
| `/customers` | Customer Accounts | `CustomerController` |
| `/users` | User Accounts | `UserController` |

Add the routes after creating the Laravel application.
